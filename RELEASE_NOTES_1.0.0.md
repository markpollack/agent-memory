# Agent Memory 1.0.0

First 1.x release, for the AgentWorks BOM 1.22.0. The version moves to 1.0.0 with the other AgentWorks members. The
API is the same as 0.5.1.

## Changes

- Jackson goes to 2.22.3 and 3.2.3, which fixes the jackson-core CVE in 2.22.2. The standalone-consumer floors are
  raised to match.
- The Jackson 2 annotations version is derived from the Jackson 2 version instead of being hardcoded.

The library's licensing terms are unchanged: Business Source License 1.1.
